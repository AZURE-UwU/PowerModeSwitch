# 联想电源模式助手

Windows 11 下的单进程 WinUI 3 托盘应用。程序在用户手动启动后监听电源适配器插拔，并在状态稳定后执行一次联想性能模式切换。

## 行为

- 接入适配器：调用 `LITSSVC` 控制码 `135`，切换平衡模式。
- 断开适配器：在稳定识别电源状态后等待用户设置的延时，再调用 `LITSSVC` 控制码 `146` 切换省电模式。
- 断电延时范围 `0–3600` 秒，`0` 表示立即切换；设置会持久化。
- 延时等待期间重新接入适配器会取消省电模式切换，并立即切换至平衡模式。
- 暂停自动切换或退出程序会取消尚未完成的断电延时切换。
- 启动时只读取当前状态，不修改现有模式。
- 用户按 Fn+Q 或通过联想软件调整模式后，程序不会持续纠正。
- 插入和拔出事件采用 1.2 秒防抖，避免 USB-C PD 协商造成重复切换。
- 关闭主窗口会隐藏到托盘，托盘菜单中的“退出”才会结束进程。
- 不创建开机启动项，不安装服务。

## 系统要求

- Windows 11 x64
- 联想 `LITSSVC` 服务，且当前机型支持控制码 `135` 和 `146`
- 无需管理员权限。当前机型允许标准用户向 `LITSSVC` 发送自定义控制码

## 使用方法

1. 打开 `CODEX\Release\win-x64\PowerModeSwitch.exe`。
2. 关闭主窗口后程序继续驻留托盘。
3. 通过托盘菜单暂停或恢复自动切换。
4. 通过托盘菜单“退出”彻底结束程序。

主程序使用标准用户权限运行，通过 Windows App SDK 直接显示系统 Toast。首次运行会创建开始菜单通知身份快捷方式；该快捷方式不创建开机启动项。若系统通知不可用，程序使用托盘气泡通知。

## 构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

输出目录：

```text
CODEX\Release\win-x64
```

构建中间文件位于 `CODEX\build`。

## 诊断

运行日志：

```text
%LOCALAPPDATA%\PowerModeSwitch\app.log
```

设置文件：

```text
%LOCALAPPDATA%\PowerModeSwitch\settings.json
```

日志不包含硬件序列号或用户个人信息。
